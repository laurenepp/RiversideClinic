# Riverside Family Clinic EMR System  
*A capstone project developed by the IT Capstone Class of 2026, AKA Kimberling Enterprises*

## Introduction
The Riverside Family Clinic EMR System is a role‑based web application designed to support daily clinical and administrative operations. This repository contains the completed system delivered as part of the IT Capstone 2026 project, including front‑end, back‑end, database, and security components.

## Mock Data Disclaimer
This project includes mock patient data used solely for demonstration and testing.  
All names, dates, and details are fictional and do not represent real individuals.  
No PII or PHI is stored in this repository.

---

## Features
- **Role‑Based Access Control (RBAC)** for Administrators, Receptionists, Nurses, and Doctors  
- **Secure Authentication** with password reset on first login  
- **Patient Registration & Search**  
- **Appointment Scheduling & Management**  
- **Nurse Intake Workflow**  
- **Provider Exam Documentation**  
- **Administrative Tools** including User Management, Staff Scheduling, and Clinic Hours  
- **Audit Logging** for login attempts  
- **Session Timeout & Basic Security Controls**
